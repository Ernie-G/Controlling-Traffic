# Controlling-Traffic

Objective: Simulate a 2 way road with a 1 lane bridge with lights on each end controlling traffic

Goal: I will learn how micro-controllers, digital inputs, and other circuit components can be used for real world scenarios

Notes: Original Code did not factor in if traffic sensor continued to stay on one side and would cause LEDs on other side to operate partially. Updated this to continue to stay green if traffic continues from one side. Demo video file is too big to upload
